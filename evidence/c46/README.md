# C46 公开研究证据

本目录发布 `C46-Aggressive-1` 的脱敏、机器可读研究摘要：

- [`public_research_summary.json`](public_research_summary.json)：精确目标权重、形成期指标、C45-A2 负面分支、同口径对照、压力、结构、产品和权限边界；
- [`../../config/strategy-research-c46-v1/001_C46-Aggressive-1_public_contract.json`](../../config/strategy-research-c46-v1/001_C46-Aggressive-1_public_contract.json)：经济假设、唯一改动、冻结门、运行预算和停止规则；
- [`../../scripts/verify_c46_public_release.py`](../../scripts/verify_c46_public_release.py)：只用 Python 标准库检查公开权重、指标差值、压力、负面证据、权限边界和目录登记。

本次没有上传第三方原始净值、基金网页响应、PDF 副本、账户数据或本机路径。摘要保留冻结合同、正式代码、唯一数值结果、第一版失败验证、纠正合同、纠正后独立验证、当前产品/结构裁决和负面候选的 SHA-256。

第一版独立验证器的失败记录没有被删除：它因为跨实现浮点求和顺序造成约 `7e-16` 的期末净值差，以及把二进制浮点转成 `Decimal` 后得到 `0.449500000000000042`，误判了字节哈希和精确压力值。纠正合同在第二版验证器运行前冻结；策略权重、阈值和主结果均未改变。第二版对所有成本、日期、压力和会计路径在 `1e-12` 容差内独立复算通过。

全部 2015—2026 结果仍属于 `contaminated formation`，不是 clean OOS、模拟盘或实盘绩效。C46 只是有独立家庭应急金、愿意维护更多基金路线的优化进取候选；C44 仍是大多数人的默认研究方案，C45 仍是更简单的高进攻方案。已有 C11 第一批继续持有、第二批继续等待。

人类可读说明见 [C46 六成权益与三层流动性收益增强进取策略](../../docs/17_C46六成权益与三层流动性收益增强进取策略.md)。
