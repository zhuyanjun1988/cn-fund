# C11 公开证据说明

本目录公开 C11 的冻结结果、独立审计、完整性评价和一份便于阅读的摘要。

- `original_result.json`：从内部冻结研究工件逐字节复制；
- `original_audit.json`：独立复算后的门槛审计；
- `integrity_evaluation.json`：时点、会计、候选谱系和证据边界评价；
- `public_result_summary.json`：面向公开阅读的去冗余摘要，不替代前三份原始工件。

内部完整日账本约 31.8 MB，没有上传。它包含由第三方行情和净值数据派生的完整
日路径，不适合在未重新确认数据许可前公开再分发。摘要保留该账本的 SHA-256，
但这也意味着公开仓库目前只能复核规则、冻结结果之间的一致性，不能从原始行情
独立重放全部 2814 个交易日。

公开 Python 模块用于复算以下确定性规则：

1. 标准 6:4 与 B60/M60/D60 的目标权重；
2. PE/PB 综合估值与 12 个月相对趋势状态判断；
3. 单资产严格超过 5 个百分点的漂移门；
4. 标记仓位严格超过 44% 的静态压力维护门。

它不是原始回测引擎的完整依赖副本，也没有基金数据抓取、账户、持仓或下单能力。
