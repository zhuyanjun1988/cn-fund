# C21—C26 公开研究证据

本目录发布一份脱敏、机器可读的研究摘要：

- [`public_research_summary.json`](public_research_summary.json)

它记录 C21—C26 的候选身份、父子谱系、目标权重、形成期指标、失败候选、产品/执行
边界和原研究工件 SHA-256。原始第三方行情、基金网站响应、PDF、账户信息和本机路径
均未上传。

所有历史结果均为 `contaminated formation`。`C23` 与 `C26` 的“突破”只表示通过了
事前形成期门并已冻结等待前瞻观察，不表示干净样本外、模拟批准、实盘批准或买卖建议。
