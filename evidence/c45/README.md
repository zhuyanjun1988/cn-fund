# C45 公开研究证据

本目录发布 `C45-Aggressive-1` 的脱敏、机器可读研究摘要：

- [`public_research_summary.json`](public_research_summary.json)：精确权重、形成期指标、同口径对照、压力、结构、产品与迁移边界；
- [`../../config/strategy-research-c45-v1/001_C45-Aggressive-1_public_contract.json`](../../config/strategy-research-c45-v1/001_C45-Aggressive-1_public_contract.json)：经济假设、唯一改动、执行、成本、冻结门和权限边界；
- [`../../scripts/verify_c45_public_release.py`](../../scripts/verify_c45_public_release.py)：使用 Python 标准库校验公开摘要的权重、差值、压力和权限边界。

本次没有上传第三方原始净值、基金网页响应、PDF 副本、账户数据或本机路径。公开摘要保留内部冻结合同、正式运行代码、数值结果、独立验证、产品/结构审计和结论报告的 SHA-256，用于对照内部不可改写工件。

全部 2015—2026 结果仍属于 `contaminated formation`，不是 clean OOS、模拟盘或实盘绩效。C45 只在研究目标层面成为用户所需的高权益 C11 后继；C44 仍是大多数人的均衡默认方案。已有 C11 第一批继续持有、第二批继续等待，真实迁移必须先核对买入批次、赎回费和同日渠道限制。

人类可读说明见 [C45 六成权益因子久期桥接进取策略](../../docs/16_C45六成权益因子久期桥接进取策略.md)。
