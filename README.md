# cn-fund：人民币可买公募基金择时研究

这是一个面向普通长期投资者的基金策略研究仓库。项目吸收 E 大长赢指数投资
计划、银行螺丝钉和孟岩/长钱账户公开表达的可迁移思想，研究标准 6:4、A 股
估值—趋势风格切换、全球多资产配置和产品可买性门禁；所有规则均明确标为自研，
不冒充任何公开作者策略的完整复刻。

结论先行：仓库现在公开八组结论，而不是把某一条历史回测包装成最终答案：

1. **标准固定 6:4**是国内固定基金池的透明基线，目标为
   `35/10/15/5/5/20/10`；基础历史净 CAGR 为 `5.78%`，最大回撤为 `32.47%`；
2. **C11**在相同 60% 权益预算内，用中证 500 综合估值和相对红利低波趋势进行
   月频风格切换；基础历史净 CAGR 为 `7.91%`，最大回撤为 `28.00%`，但历史只有
   两次状态切换，状态仅为 `PASS_RESEARCH_ONLY`；
3. **G6-Standard-1**的全球资产候选因三年滚动稳健性与联合压力门失败，已经否决，
   只保留为研究参考；
4. **C21-Standard-1**用自由现金流、红利低波和中证500质量成长重构 60% 权益，
   2015—2026 污染形成期净 CAGR 为 `10.75%`、最大回撤为 `26.64%`，当前只冻结为
   收益型研究基准；
5. **C23/C26**在 2019—2026 受限窗口通过了材料性形成期门，但窗口排除了 2015
   股灾，且自由现金流历史大量来自指数发布前回溯；C21-S2、C22、C24、C25 均已
   按事前门否决。C23/C26 不自动替代已经手工建立的 C11。
6. **C44-Standard-1**使用 50% 成熟三因子权益、30% 黄金、15% 三经理固收+和
   5% 现金；在 2015—2026 同窗口、次一共同会话执行下，形成期净 CAGR 为
   `10.47%`、最大回撤为 `23.90%`、Calmar 为 `0.438`。它通过了冻结的 C11
   替换门，现为研究默认后继策略；已有 C11 仓位仍须按费率分批迁移，不是立即清仓授权。
7. **C45-Aggressive-1**保留 C21 的 60% 权益因子组合，只把 15% 防守路线改为
   可得性约束的国债—7至10年国开债久期桥接；形成期净 CAGR 为 `11.09%`、最大
   回撤为 `26.19%`、Calmar 为 `0.423`，极端确定性压力为 `44.25%`。它是明确要求
   更高权益用户的 C11 研究后继；C44 仍是大多数人的均衡默认方案。
8. **C46-Aggressive-1**没有继续增加高 Beta，而是把 C45 的 5% 现金改为 3% 多经理
   固收+、1% 短久期国开债和 1% 现金；形成期净 CAGR 为 `11.33%`、最大回撤为
   `26.12%`、Calmar 为 `0.434`。相对 C45，年化提高 `0.236` 个百分点且回撤小幅改善，
   但极端确定性压力已到 `44.95%`，内部现金只剩 1%。它只适合有独立应急金、愿意
   维护更多产品路线的优化进取用户；C44/C45 的默认定位不变。

> 本仓库仅用于只读研究与模拟。没有账户、持仓、凭据或下单能力；基金代码是
> 历史研究代理，不是买入推荐。历史表现不代表未来收益。

## 研究目标

最终希望得到一套可在中国境内使用人民币购买公募基金、ETF、ETF 联接、LOF
和合规 QDII 产品执行的规则，能够在每个有效决策时点明确回答：

1. 当前应持有什么资产类别；
2. 每类目标权重是多少；
3. 哪只基金满足身份、规模、跟踪、费用、流动性和限购要求；
4. 对给定模拟账户，应买入、卖出或持有多少；
5. 哪些数据或产品障碍会使订单失败关闭。

研究目标不是承诺，而是候选晋级门槛。早期全球策略使用下表的进取目标；用户随后
明确接受更低收益来换取国内组合的稳定性，因此 C11 单独冻结了 `CAGR >= 7.5%`、
`MDD <= 30%` 等形成期门，不能把两个阶段的门槛混为同一个收益承诺：

| 指标 | 目标 |
|---|---:|
| 扣除成本后的长期净 CAGR | `>= 10%` |
| 常态历史最大回撤 | `<= 35%` |
| 极端压力下最大损失 | `<= 45%` |
| Calmar | `>= 0.30` |
| 滚动稳健性 | 不能只靠少数年份贡献全样本收益 |

## 国内 6:4 与 C11 的诚实评价

国内固定基金池由三只权益基金、三只债券基金和现金组成。标准 6:4 固定持有；
C11 不改变 60% 总权益，只在中证 500 增强和红利低波之间切换。

| 项目 | 标准固定 6:4 | C11 |
|---|---:|---:|
| 基础情景净 CAGR | `5.7802%` | `7.9132%` |
| 基础情景最大回撤 | `32.4715%` | `27.9991%` |
| 基础 Calmar | `0.1780` | `0.2826` |
| 最大标记静态压力 | `43.8435%` | `42.0621%` |
| 极端成本与 10 日延迟 CAGR | `5.5140%` | `7.1227%` |
| 交易次数 | `5` | `10` |

区间为 2015-01-05 至 2026-08-03，共 2814 个共同交易日。产品成立前使用冻结
代理，C11 又是在看过 C1—C10 结果后形成，所以这些都是**污染形成期证据**。
C11 只有两次真正状态切换，没有不变参数的前瞻期，不能称为 clean OOS、仿真

## C21—C26 的最新研究结论

C21 不提高 60% 总权益预算，而是把权益拆为自由现金流、红利低波和中证500质量
成长；C23 再从质量成长中拿出 5% 配置创业板成长动量卫星；C26 只把 C23 的 15%
短久期国开债换成 15% 的 7—10 年国开债。

不同窗口的标题数字不能直接排名：

| 策略 | 窗口 | 净 CAGR | 最大回撤 | Calmar | 当前状态 |
|---|---|---:|---:|---:|---|
| C21 | 2015-01—2026-07 | 10.7502% | 26.6377% | 0.4036 | 冻结研究基准 |
| C23 | 2019-01—2026-07 | 13.8272% | 10.1695% | 1.3597 | 受限窗口形成突破，等前瞻 |
| C26 | 2019-01—2026-07 | 14.2068% | 9.9398% | 1.4293 | 受限窗口形成突破，等前瞻 |

C23/C26 的共同窗口只有 1,805 个会话，其中自由现金流路径有 1,427 个会话
（79.06%）早于 `932365` 指数的 2024-12-11 发布日，只有 240 个会话（13.30%）

优于 C11。C26 尚未完成自身的 FCF 发布前路径 -2%/-4% 专项敏感性。

## C44：通过 C11 替换门的研究后继策略

C44 不再搜索短窗口内的创业板或长债最优权重，而是把两个独立研究模块放进一个新合同：

- 15% `217027` 大盘质量；

## G6 的诚实评价

历史区间为 2015-01-05 至 2026-07-30，共 2740 个共同交易日。全部结果都是
**污染的形成期证据**：结构选择看过历史结果，估值历史也不是完整的同期 PIT
档案，因此不能称为 clean OOS。

| 项目 | G6-Standard-1 | 评价 |
|---|---:|---|
| 基础情景净 CAGR | `10.9720%` | 达到 10% 目标 |
| 基础情景最大回撤 | `13.3510%` | 低于 35% |
| Calmar | `0.8218` | 达标 |
| 最大静态极端冲击 | `44.0249%` | 低于 45% |
| 历史路径 + 极端冲击叠加 | `46.8492%` | **超过 45%，失败** |
| 32 个滚动三年窗口中 CAGR >=10% | `43.75%` | **低于预注册 50%，失败** |
| 24 个滚动五年窗口中 CAGR >=10% | `75.00%` | 通过 |
| 单边成本 100bp 的净 CAGR | `10.7240%` | 成本敏感性尚可 |
| 延迟 10 日、单边成本 250bp 的净 CAGR | `9.7441%` | 压力下低于最终 10% 目标 |

为何静态压力“通过”但极端目标仍“失败”：静态压力只计算某日组合权重立即遭遇
给定冲击的损失；路径叠加先保留组合从此前高点已经发生的净值回撤，再在当日
仓位上施加冲击。用户的原始目标是极端情况下最大回撤不超过 45%，因此更完整
的 `46.85%` 口径优先，不能用较窄的静态口径替代。

完整评价见 [历史结果与否决结论](docs/05_历史结果与否决结论.md)。2740 日账本
及独立复算入口位于 [公开证据目录](evidence/g6-standard-1/)。

## G6 的规则是什么

长期核心权重如下：

| 袖套 | 历史代理 | 核心目标 |
|---|---|---:|
| 沪深 300 | `510300` | 5% |
| 中证 500 | `510500` | 5% |
| 创业板 | `159915` | 5% |
| 恒生指数 | `000071` | 0% |
| 标普 500 | `050025` | 15% |
| 纳斯达克 100 | `270042` | 20% |
| 黄金 | `000216` | 20% |
| 债券 | `161120` | 30% |

每年 3、6、9、12 月最后一个共同交易日收盘后计算信号，估值观测必须严格早于
决策日，计划在随后第 2 个共同交易日执行：

- 低估接收者：估值分位最低，且分位 `<=20%`；或分位 `<=40%` 且 10 个月
  动量 `>-10%`；
- 高估出资者：非接收者、核心权重至少 2.5%、估值分位 `>=65%`，并选择其中
  估值最高者；
- 两端同时成立时，从高估袖套转移 2.5% 到低估袖套；
- 任一端缺失或数据不完整时，取消倾斜并回到核心目标；
- 倾斜只在权益袖套内部转移，不从黄金或债券融资，不提高 50% 的核心权益预算。

这不是 E 大 150 计划的复刻。`50/20/30`、2.5% 批次、季度频率和所有阈值均为
本项目自研参数；E150 的 `tradeUnit/150`、单位库存或剔除境外后的归一化比例
从未作为市值权重、现金比例或风险参数。

- `050025` 当时显示暂停申购，页面同时展示单日 100 元上限；
- `270042` 当时显示限大额，单日累计上限 5 元；
- 因此新组合无法按 15%/20% 目标一次性建立两个 QDII 袖套；
- 不允许拆单、跨份额或追买高溢价场内产品规避限购；
- 场内替代品必须在拟执行时重新检查跟踪关系、溢折价、价差、深度和交易状态。

任何新的“今天买什么、卖什么”都必须使用新的收盘后信号和同日产品状态，不能
从这个仓库里的历史快照外推。

## 快速开始

项目只依赖 Python 标准库，要求 Python 3.11 或更高版本。

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -e .
make test PYTHON=.venv/bin/python
make verify-evidence PYTHON=.venv/bin/python
make policy PYTHON=.venv/bin/python
make standard-64-policy PYTHON=.venv/bin/python
make c11-policy PYTHON=.venv/bin/python
make verify-c44-public-release PYTHON=.venv/bin/python
make verify-c45-public-release PYTHON=.venv/bin/python
make verify-c46-public-release PYTHON=.venv/bin/python
```

不安装包也可以直接运行：

```bash
PYTHONPATH=src python3.12 -m cn_fund_strategy.interfaces.public_cli policy
PYTHONPATH=src python3.12 -m cn_fund_strategy.interfaces.public_cli \
  verify-evidence \
  --ledger evidence/g6-standard-1/daily_accounting_ledger.json \
  --summary evidence/g6-standard-1/public_result_summary.json
```

用显式输入演示季度信号计算：

```bash
PYTHONPATH=src python3.12 -m cn_fund_strategy.interfaces.public_cli decision \
  --session 2026-09-30 \
  --valuation-session 2026-09-29 \
  --valuations 'CN300=0.70,CN500=0.80,GROWTH=0.15,HK=0.50,SP500=0.75,NASDAQ=0.90' \
  --momentum 'CN300=0.05,CN500=0.03,GROWTH=0.10,HK=0.02,SP500=0.08,NASDAQ=0.12'
```

该命令只计算经济目标，不检查基金产品可买性，也不会生成可执行订单。

复算 C11 当前研究示例：

```bash
PYTHONPATH=src python3.12 -m cn_fund_strategy.interfaces.public_cli c11-decision \
  --previous-state M60 \
  --pe-percentile 0.800595 \
  --pb-percentile 0.760516 \
  --relative-trend 0.171615
```

该命令只演示冻结状态机。输入分位必须来自满足点时时钟的数据；命令不会自行抓取
净值、判断产品限购或访问账户。

## 数据为什么没有全部上传

公开仓库保留可独立复算核心指标的日会计账本，但不上传：

- 原始网站响应、PDF、行情数据库和第三方数据副本；
- 凭据、cookies、浏览器状态或任何账户数据；
- 本机绝对路径、虚拟环境、缓存、日志；
- 74 MB 的内部内容寻址重复副本和数千条开发审计账本；
- 已淘汰候选的全部中间工件。

C11 额外公开了冻结结果、审计与完整性评价，但 31.8 MB 完整日账本暂未上传；
公开摘要保留账本 SHA-256。公开代码可以复算策略规则，却不能在缺少原始授权数据
时重放全部历史路径。

C21—C26、C44、C45 和 C46 采用相同原则：公开策略身份、权重、形成期与压力指标、失败候选、关键数据
边界和内部原始工件 SHA-256，不上传第三方原始指数/净值响应。这些公开摘要不是一套
可独立重放全部历史路径的数据包。

这些内容对公开理解 G6 的边际价值低，且部分数据的许可不适合再分发。公开摘要
保留原始关键工件 SHA-256，便于在原研究环境中核对血缘。详见
[数据回测与复现](docs/06_数据回测与复现.md)。
