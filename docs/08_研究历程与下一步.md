# 研究历程、已否决方向与下一步

## 1. 做过什么

项目最初从境内公募候选池出发，逐步完成：

- 基金身份、份额、规模、费用和生命周期领域模型；
- ETF/场外基金分类、准入、同类评分和隔离状态；
- E150 259 次调整、416 个买卖腿的行为上下文；
- 螺丝钉和孟岩公开理念的交叉整理；
- 多轮资产配置、估值、趋势和调仓候选；
- 点时数据、成本、分红、结算、限购和压力测试检查；
- G6 固定核心 + 季度估值倾斜的完整历史会计。
- 国内标准 6:4 基线及 C11 月频估值—相对趋势风格切换研究。

大量工作属于研究基础设施，并不直接等于策略收益。公开版只保留能解释最终经济
判断、复算关键数字和继续开发的高价值部分。

## 2. 已否决方向的教训

### 过小的 A 股宽基池

只在沪深 300 等少数指数中选择，无法充分表达 A 股大小盘、风格、行业轮动和
多资产分散。候选池必须从资产袖套和精确指数族设计，而不是先挑几个代码。

### 不择时长期持有单一指数

它与项目学习“低估买、高估卖、动态平衡”的目标不一致。Beta 底座有价值，但
不能因此忽略 A 股估值周期和轮动。

### 把 E150 单位当权重

公开单位账本不是市值账户。用 `tradeUnit/150` 或剔除境外后的归一化比例推权益
上下限、现金率或压力参数，会把不可比单位伪装成精确风险数据，已明确禁止。

### 只解释事件日

能讲通“为什么那天买”不够；候选规则还必须解释为什么大量非事件日没有买。
只看发车日容易后验故事化并低估误触发。

### CORE3 三核心 65% 结构

三份官方事实表显示其信息技术行业合计暴露约 17.22%，稳健高于冻结 15% 门，
该结构已被否定。不能在同一候选里放宽门、改权重或追加因子修补。

### G6

全样本 CAGR 达标、常态回撤低，但路径叠加极端压力 46.85% 和滚动三年门失败。
这说明“漂亮总曲线”不足以证明长期可用。

## 3. 哪些工程工作仍有价值

高价值、应复用：

- 资产袖套—指数—产品三层模型；
- 点时字段、生命周期、限购和费用门；
- 总回报、数量/市值/现金和结算会计；
- 合成测试、固定事件压力和不可回填证据；
- 失败关闭的信号/产品/订单分层；
- E150 的多层状态机认识。

低优先级、按需再做：

- 为每个旧候选补齐所有内部时间戳和内容寻址副本；
- 对已稳健否定的结构继续增加因子和微型合同；
- 在没有新经济假设时扩大几百只同质基金；
- 为公开仓库搬运不能再分发的原始第三方数据。

## 4. 最新研究选择

G6失败后，研究范围回到用户冻结的国内基金池，并把固定60/40作为新的经济假设，
而不是在G6原候选里修补阈值。

- 标准6:4精确使用`35/10/15/5/5/20/10`，基础历史CAGR为5.78%，最大回撤
  32.47%，作为低模型风险基线；
- C11固定60%总权益，只在中证500增强与红利低波之间切换，基础历史CAGR为
  7.91%，最大回撤28.00%；
- C11通过13个形成期研究门，成为当前固定池中最值得继续观察的候选；
- 该选择仍然受“看过C1—C10”和“全历史只有两次状态切换”约束，不能升级为
  干净OOS、模拟批准或实盘结论。

## 5. 建议的最小下一阶段

### P0：冻结 C11 并收集前瞻证据

- 不修改PE/PB综合分位、30/70阈值、12个月趋势、5%漂移门和44%压力门；
- 每个月末保存当时可得输入、信号、目标和哈希，不回填；
- 重点等待新的状态冲突和状态切换，不能只用更多M60持有日冒充独立验证；
- 继续保留标准6:4作为同输入、同成本的并行对照。

### P1：补产品执行证据

- 在每个拟执行时点核验六只基金同一份额的合同、费率、净值、申赎和限购；
- 记录未知价申赎、确认、到账和现金占用，不把下一交易日收盘价直接当真实成交；
- 006729增强能力显著衰减或产品身份变化时，只按事前退出门处理。

### P2：有条件再激活

- 完整PIT费率与限购历史；
- 全量第三方原始数据再分发；
- 所有旧候选的内容寻址修复；
- 新阈值网格、更复杂优化器或机器学习因子。

P2只有在它会改变C11晋级决定、数据许可明确且P0/P1已完成时再做。当前不应创建
C12去微调历史收益。

## 6. 项目管理停止规则

- 一个任务不能说明会改变哪个最终决定，就不启动；
- 同一阻碍连续三次尝试仍无实质变化，停止并暴露；
- 候选被一项稳健硬门否定后，关闭该候选，不在原 ID 内修补；
- 回测基础会计和未来函数是关键事项，不能偷懒；
- 文档数量、合同数量和测试数量不是进度指标；
- 第一优先级始终是从真实输入到明确决策的最短可验证闭环。
