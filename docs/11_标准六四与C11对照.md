# 标准 6:4 与 C11：怎么理解和选择

## 结论

标准6:4是低模型风险的长期基线；C11是历史表现更好的低频风格切换研究候选。
现有证据足以支持“继续冻结研究C11”，不足以支持“C11已经可以替代基线实盘”。

## 同口径比较

| 维度 | 标准固定 6:4 | C11 |
|---|---|---|
| 总权益/债券/现金 | 60%/30%/10% | 60%/30%/10% |
| 权益内部 | A500 35%、500增强10%、红利低波15% | A500固定10%，500增强与红利低波在25/25、40/10、10/40间切换 |
| 主动信号 | 无 | 月末综合估值+12个月相对趋势 |
| 普通再平衡 | 单资产偏离严格>5% | 同样的>5%门 |
| 压力维护 | 标记压力严格>44% | 同样的>44%门 |
| 基础历史净CAGR | 5.78% | 7.91% |
| 基础历史最大回撤 | 32.47% | 28.00% |
| 历史交易次数 | 5 | 10 |
| 模型风险 | 低 | 中等，存在阈值、趋势、状态和路径依赖 |
| 关键证据弱点 | 静态历史未必代表未来 | 只有2次状态切换，且形成过程污染 |

## C11历史上为什么更好

从对照实验看，可能有两类来源：

1. 把权益风格仓放到中盘增强或红利低波的不同阶段，历史路径优于静态平均目标；
2. 006729在实际映射阶段的指数增强收益提高了组合结果。

但现有数据不能把它们识别为未来稳定Alpha。只有两次状态切换，任何一次恰好处于
有利历史阶段，都可能显著改变11年CAGR。006729未来增强衰减也会缩小优势。

## 标准6:4什么时候更有优势

标准基线更适合以下约束：

- 不愿维护点时估值和全收益指数数据；
- 无法接受状态机可能多年保持一个风格；
- 更看重少犯操作错误，而不是追求历史多出的年化收益；
- 真实平台限购、申赎和份额变化使状态切换难以按目标完成。

它的弱点是不会利用明显的风格轮动，历史收益和回撤都逊于C11。

## C11什么时候才值得进一步推进

C11下一阶段应该保持参数完全不变，收集以下新证据：

1. 每个月末按冻结时钟生成不可回填的前瞻状态；
2. 保存当时实际可得的PE、PB和两条全收益指数端点；
3. 保存六只基金同一份额的净值、费率、申赎状态和限购；
4. 用模拟会计记录信号日、可执行日、确认日、成本和仓位漂移；
5. 至少观察新的状态冲突和状态切换，而不是只累计更多同状态日；
6. 006729持续相对中证500基准落后时，按事前产品退出规则处理，不能事后换基金美化回测。

在这些证据形成前，`PASS_RESEARCH_ONLY`只能说明C11通过了本轮形成期门槛。

## 与G6的关系

G6研究了包含美股、黄金和跨境QDII的全球资产配置，但三年滚动稳定性和联合压力
门失败，已经被否决。标准6:4与C11只讨论当前固定国内基金池，不能直接用二者的
历史收益率判断全球分散是否无效；资产范围、数据代理和风险来源完全不同。

## 当前项目选择

- **透明基线**：保留标准6:4，作为所有主动方案的共同对照；
- **当前研究候选**：冻结C11，不再通过历史参数搜索提高收益；
- **当前审批状态**：C11未获模拟或实盘批准；
- **下一步**：前瞻影子验证与产品执行证据，而不是开启C12微调阈值。

这一区分很重要：研究上可以认为C11“值得继续”，资金执行上仍必须承认证据未闭环。
