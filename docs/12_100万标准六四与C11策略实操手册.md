# 100万元标准6:4与C11基金策略实操手册

版本：1.0
研究截止：2026-08-04
适用范围：中国境内人民币场外公募基金账户
状态：研究与模拟用途，不是个性化投资建议或实盘批准

> 核心结论：对大多数长期投资者，标准6:4已经足够。它比C11简单、少交易、少依赖数据，也更容易长期坚持。C11只适合愿意每月维护点时数据、严格执行状态机、并接受模型可能失效的人。

## 1. 先看结论：应该选哪一个

| 问题 | 标准6:4 | C11 |
|---|---|---|
| 总体结构 | 60%权益、30%债券、10%现金 | 60%权益、30%债券、10%现金 |
| 权益内部 | 固定35% A500、10%中证500增强、15%红利低波 | A500固定10%，其余50%在中证500增强和红利低波之间切换 |
| 判断频率 | 月末只看仓位漂移和压力 | 月末计算估值与12个月相对趋势 |
| 主要优点 | 简单、透明、低换手、容易坚持 | 历史上收益更高、回撤更低 |
| 主要缺点 | 不利用风格轮动 | 规则复杂、只有两次历史切换、模型风险更高 |
| 适合人群 | 大多数长期投资者 | 能维护数据和纪律的进阶研究者 |
| 当前研究状态 | 共同基线 | PASS_RESEARCH_ONLY，未获仿真或实盘批准 |

标准6:4的历史基础场景净年化为5.78%，最大回撤32.47%；C11为7.91%和28.00%。这些结果来自2015-01-05至2026-08-03的污染形成期回放，部分产品成立前使用指数或债券代理，不能当作未来收益承诺。

本文提供两类初始建仓方法：

1. 一次性精确建仓：从第一天起达到策略目标，经济逻辑最干净；
2. 分阶段建仓：先买防守仓和一半权益，剩余权益用50周定投完成，降低一次性入场的心理压力。

无论选择哪一种，都应在开始前一次性确定，不能因为短期涨跌在两种方法之间反复切换。

## 2. 执行前的五个前提

在投入100万元前，必须同时满足：

- 这100万元是至少5年不用的长期资金；
- 家庭紧急备用金、未来3年明确支出和高息负债已经另行处理；
- 能接受组合在极端时期出现30%以上账面回撤；
- 理解债券基金也会亏损，红利低波也仍然是股票；
- 愿意按规则记录和复核，不根据新闻、情绪或短期排行榜临时换基金。

如果其中任意一项不满足，不应通过降低定投频率来掩盖风险，而应先降低总投资金额或权益比例。本文的比例是策略研究对象，不是所有家庭的统一答案。

### 3.1 022430为什么是核心

022430主要通过目标ETF跟踪中证A500。它承担的是全组合中最稳定、最容易解释的A股宽基暴露。标准6:4给它35%，因为核心仓应明显大于卫星仓；C11只给10%，是为了把50%的权益风格预算留给中证500增强和红利低波轮换。

它不是指数增强基金。其主要任务是尽量跟踪指数，而不是依赖基金经理主动选股获得持续超额。基金转型后合同生效日为2024-11-18，真实产品历史较短，长期回放中的早期结果主要是指数代理，不是这只基金真实存在十年的业绩。

### 3.2 006729为什么不能成为唯一核心

006729跟踪中证500方向，同时使用量化模型争取超越指数。中证500更偏中盘，与A500存在部分重叠，但风格弹性更高。历史增强效果是C11收益的重要来源，也是最大的模型风险之一。

如果未来基金经理变化、规模扩张、模型拥挤或增强收益连续衰减，006729可能只剩下中证500Beta，甚至阶段性跑输基准。因此标准策略只配置10%；C11即使处于M60，单只上限也控制在40%，而不是押注全部权益。

### 3.3 021550为什么是防守型权益而不是债券

021550主要跟踪中证红利低波动100指数。它通过红利、价值和低波筛选降低相对波动，往往偏向银行、能源、公用事业等成熟行业。

“低波”只表示相对其他股票波动可能较低，不表示不会亏损。系统性熊市中它仍可能显著下跌；行业集中也可能让它长期落后于成长和中小盘。它的作用是和006729形成风格互补，不是替代债券。

### 3.4 两只超短债为什么都保留

006662和012773各占5%，主要目的不是提高收益，而是分散基金管理人、信用组合、运营和申赎风险。超短债久期较短、波动通常较小，但仍可能因信用利差、赎回冲击或债市波动发生亏损。

### 3.5 007169为什么占20%

007169主要跟踪1-3年国开行债券指数，提供与企业信用债不同的风险来源。它承担防守仓的大部分比例，目标是降低组合整体波动并提供再平衡资金。

政策性金融债信用风险通常较低，但并非存款或保本产品。市场利率上升时，债券价格仍会下降。

## 4. A类份额、申赎和分红设置

本文固定使用上述A类代码，不在执行时静默替换成C类。A类通常更适合预计长期持有的资金，但不同销售渠道的申购费折扣、赎回费和C类销售服务费可能不同。真实操作前，应在同一销售平台比较总成本，不能只看“买入费率0折”字样。

所有六只基金均为场外开放式份额。买入是按金额申购，成交净值通常在提交时未知；赎回往往按份额提交。必须以销售页面当天显示的截止时间、确认日、到账日、费用和限额为准，不能把盘中估值当作实际成交价。

建议分红设置：

| 资产 | 默认分红方式 | 原因 |
|---|---|---|
| 022430、006729、021550 | 红利再投资 | 保持权益总回报暴露，减少现金闲置和手工追投 |
| 006662、012773、007169 | 现金分红 | 补充10%现金槽和再平衡资金，降低防守仓现金流再次锁定 |
| CASH | 不适用 | 本身就是流动性槽位 |

如果投资者明确处于长期积累期，也可以把债券基金设置为红利再投资，但必须把新增份额计入债券市值，并在再平衡时统一计算。基金不一定每年分红，分红设置只决定发生分红时如何处理，并不创造额外收益。

设置步骤：

1. 先完成基金申购并等待份额确认；
2. 在持仓详情中进入“分红方式”；
3. 核对基金代码和A类份额；
4. 权益三只选择“红利再投资”，债券三只选择“现金分红”；
5. 保存平台确认截图或记录生效日期；
6. 每半年复核一次，防止渠道迁移或份额转换后设置变化。

## 5. 标准6:4策略原理

[[ALLOCATION_BAR]]

标准6:4目标为：

| 代码 | 目标比例 | 100万元目标金额 |
|---|---:|---:|
| 022430 | 35% | 350,000元 |
| 006729 | 10% | 100,000元 |
| 021550 | 15% | 150,000元 |
| 006662 | 5% | 50,000元 |
| 012773 | 5% | 50,000元 |
| 007169 | 20% | 200,000元 |
| CASH | 10% | 100,000元 |

这不是神奇配方。60%权益负责长期增长，30%债券降低波动并提供再平衡弹药，10%现金处理生活、结算和执行摩擦。权益内部用“宽基核心 + 中盘增强 + 红利低波”分散规模和风格；债券内部用“两只超短债 + 国开债”分散信用、利率和管理人风险。

标准策略不根据估值或新闻改变上述目标。它依靠三种纪律：

- 长期持有预先定义的风险预算；
- 用新增资金优先买入低于目标的资产；
- 偏离足够大时卖高买低，恢复目标。

## 6. 标准6:4如何建立100万元初始仓

### 6.1 路径A：一次性精确建仓

适合已经理解权益风险、家庭备用金独立、能够承受建仓后立即下跌的人。

在第一个通过执行检查的开放日T，按销售平台显示的截止时间之前提交：

| 操作 | 代码 | 金额 | 操作原因 |
|---|---|---:|---|
| 买入 | 022430 | 350,000元 | 建立A股宽基核心 |
| 买入 | 006729 | 100,000元 | 建立中盘增强卫星 |
| 买入 | 021550 | 150,000元 | 建立红利低波卫星 |
| 买入 | 006662 | 50,000元 | 第一层超短债防守 |
| 买入 | 012773 | 50,000元 | 第二管理人短债防守 |
| 买入 | 007169 | 200,000元 | 建立国开债核心防守 |
| 保留 | CASH | 100,000元 | 永久现金目标，不参与定投扣款 |

T日必须先确认：代码、名称、A类份额、申购开放、单日限额不低于计划金额、销售截止时间、申购费和银行卡限额。若任一目标基金不可申购，不把该金额临时加到另一只权益基金，而是留在现金槽，记录“产品门阻塞”，待恢复后补齐。

### 6.2 路径B：先建底仓，再用50周完成权益

这是更适合担心一次性入场时点的行为友好方案。代价是前期现金较多，如果市场持续上涨，收益可能低于一次性建仓。

T日初始买入：

| 操作 | 代码 | 初始金额 |
|---|---|---:|
| 买入 | 022430 | 175,000元 |
| 买入 | 006729 | 50,000元 |
| 买入 | 021550 | 75,000元 |
| 买入 | 006662 | 50,000元 |
| 买入 | 012773 | 50,000元 |
| 买入 | 007169 | 200,000元 |
| 永久保留 | CASH-CORE | 100,000元 |
| 定投储备 | CASH-DCA | 300,000元 |

初始状态是30%权益、30%债券、10%永久现金和30%定投储备。它不是最终60/40，而是一条预先定义的50周建仓路径。

### 6.3 三条定投如何设置

从T日后的第一个可设置周四开始，建立三条“普通定投”，关闭智能定投、均线加码、估值加码和止盈计划：

| 基金代码 | 每周四扣款 | 50周累计 | 最终总投入 |
|---|---:|---:|---:|
| 022430 | 3,500元 | 175,000元 | 350,000元 |
| 006729 | 1,000元 | 50,000元 | 100,000元 |
| 021550 | 1,500元 | 75,000元 | 150,000元 |
| 合计 | 6,000元 | 300,000元 | 600,000元权益 |

周四没有历史上的必然优势，只是固定操作日。遇到非开放日，以平台顺延或失败提示为准，不手工猜测净值。三条计划必须从300,000元定投储备扣款，不能误用100,000元永久现金目标。

第50次扣款确认后：

1. 关闭三条自动定投；
2. 用全部基金确认市值和现金计算实际权重；
3. 若没有单只资产偏离目标严格超过5个百分点，不做额外交易；
4. 若超过5个百分点，优先用剩余现金和新增资金纠偏，再考虑赎回；
5. 进入常规月末检查。

分阶段建仓期间，不拿“最终目标”每天逼迫再平衡，而是按每周推进的计划目标检查。否则刚开始的30%定投储备会被错误识别为现金超配，导致策略第一天就把定投计划全部取消。

## 7. 标准6:4什么时候买、什么时候卖

### 7.1 月末权重计算

在每月最后一个开放日的净值全部确认后，计算：

`单只资产权重 = 该资产确认市值 / 包含现金的组合总市值`

如果任意资产与目标比例的绝对差严格超过5个百分点，触发再平衡：

`目标交易金额 = 目标比例 x 当前组合总市值 - 当前资产市值`

- 结果为正：买入；
- 结果为负：卖出绝对值；
- 等于或小于5个百分点：不交易。

赎回通常按份额提交。可先用最新确认净值估算赎回份额，但最终以基金确认结果为准；小额残差留到下次检查，不为几十元反复交易。

### 7.2 标准策略交易决策表

| 场景 | 买什么 | 卖什么 | 为什么 |
|---|---|---|---|
| 新建组合 | 按目标买六只基金，留10%现金 | 无 | 建立战略风险预算 |
| 定投阶段 | 每周买022430、006729、021550 | 无 | 分50周完成剩余权益，不预测短期涨跌 |
| 某基金低于目标超过5个百分点 | 买入该基金 | 优先用新增现金；不足时卖超配资产 | 恢复风险预算，机械低买 |
| 某基金高于目标超过5个百分点 | 买入其他低配资产或补现金 | 卖出该高配基金 | 控制集中度，机械高卖 |
| 权益大跌但偏离未超过5个百分点 | 不额外交易，定投照常 | 不止损 | 避免小波动导致频繁操作 |
| 权益上涨导致压力值严格超过44% | 买债券或补现金 | 卖超配权益 | 防止权益市值膨胀突破风险预算 |
| 产品暂停申购或限购 | 暂不买，金额留现金 | 不用相似基金临时替代 | 产品门失败关闭，避免策略漂移 |
| 个人资金期限或风险承受力改变 | 重新制定新策略 | 按新的家庭资产计划处理 | 这是投资者约束变化，不是市场择时 |

### 7.3 一个100万元的漂移例子

假设组合总市值仍约100万元，022430上涨后达到42%，而目标是35%，偏离+7个百分点；006729只有7%，目标10%；债券和现金也略低。

此时022430目标市值为350,000元，实际约420,000元，应计划卖出约70,000元。赎回款优先补足006729、低配债券和现金，而不是因为022430“赚了30%”就固定卖一半。

标准策略只看当前市值权重，不看某只基金的持仓收益率。不同买入批次成本不同，以“收益率达到30%卖一半”为规则会让同一组合因为开户日期不同而产生完全不同的风险预算，因此本文不采用该规则。

### 7.4 标准策略明确不做什么

- 不因为单只基金盈利30%就卖出一半；
- 不因为组合回撤15%就止损；
- 不因新闻临时增加半导体、医药或其他行业基金；
- 不用最近一年收益排名替换基金；
- 不在5个百分点以内做小额再平衡；
- 不把现金分红误认为额外收益，分红前后总财富需要连续计算。

## 8. C11策略原理

[[C11_FLOW]]

C11不改变60%总权益，而是在006729与021550之间做月频风格切换。它结合估值和趋势：估值回答“中证500是否便宜或昂贵”，相对趋势回答“资金是否已经确认中盘或红利风格”。

### 8.1 三个状态

| 代码 | B60初始均衡 | M60中盘倾斜 | D60红利倾斜 |
|---|---:|---:|---:|
| 022430 | 10% | 10% | 10% |
| 006729 | 25% | 40% | 10% |
| 021550 | 25% | 10% | 40% |
| 006662 | 5% | 5% | 5% |
| 012773 | 5% | 5% | 5% |
| 007169 | 20% | 20% | 20% |
| CASH | 10% | 10% | 10% |

B60只承担初始化。离开B60以后，信号没有共同确认时保留前一状态，不会自动返回B60。这种“有记忆”设计减少来回交易，但也会让策略反应变慢。

### 8.2 综合估值

每月末，使用决策日前两个上交所交易日的中证500 PE_TTM和PB历史。每个序列至少1260个交易日、最多2520个交易日。分别计算包含当前值的历史中位秩分位，再取平均：

`V = (PE历史分位 + PB历史分位) / 2`

实际冻结实现使用上述平均值。原合同简写可能被理解为PE和PB必须分别越过阈值，但全部C11历史结果都按综合平均生成，本文以真实实现为准，不改写冻结结果。

### 8.3 12个月相对趋势

使用中证500和中证红利低波动100的全收益指数，计算：

`R = 中证500的12个月财富因子 / 红利低波的12个月财富因子 - 1`

- R大于0：中证500过去12个月相对更强；
- R小于0：红利低波过去12个月相对更强。

这是财富因子之比，不是两个收益率简单相减。

### 8.4 状态规则

| 条件 | 新状态 | 买卖逻辑 |
|---|---|---|

低估加趋势确认，目的是避免在持续下跌中只因“便宜”不断抄底；高估加趋势转弱，目的是避免强势行情尚未结束就过早卖出。

## 10. C11什么时候买、什么时候卖

### 10.1 正式决策时钟

1. 每月最后一个共同交易日收盘后计算信号；
2. 估值数据截止到该日前两个上交所交易日；
3. 相对趋势使用精确的12个月月末全收益端点；
4. 状态切换最早在下一共同交易日、且销售渠道允许时执行；
5. 真实场外基金订单必须等待净值确认、份额确认和赎回到账；
6. 如果任何输入或产品门未知，现有账户保持原状态，新账户停在B60或现金防守，不临时发明参数。

### 10.2 状态切换对应的名义交易

以下金额假设组合总市值正好100万元，且切换前完全处于目标；真实金额必须用当前组合总市值和实际市值重新计算。

| 状态变化 | 买入 | 卖出 | 原因 |
|---|---:|---:|---|
| B60到M60 | 买006729约150,000元 | 卖021550约150,000元 | 低估且中盘相对转强 |
| B60到D60 | 买021550约150,000元 | 卖006729约150,000元 | 高估且中盘相对转弱 |
| M60到D60 | 买021550约300,000元 | 卖006729约300,000元 | 从中盘倾斜切换到红利倾斜 |
| D60到M60 | 买006729约300,000元 | 卖021550约300,000元 | 从红利倾斜切换到中盘倾斜 |
| 信号冲突或中间区 | 不买 | 不卖 | 保留前状态，避免噪声交易 |

实际订单公式仍是：

`目标交易金额 = 新状态目标比例 x 当前组合总市值 - 当前资产市值`

卖出需按平台规则换算成份额。先执行赎回会产生到账等待；先买入又可能占用额外现金。没有独立流动性时，应分成“赎回确认 - 资金到账 - 买入确认”的结算批次，不假设同日无摩擦交换。

### 10.3 漂移和压力维护

C11继承与标准策略相同的单资产严格超过5个百分点漂移门。除此之外，每个交易日可以用当前市值估算静态压力：权益假设下跌60%、两只超短债下跌3%、国开债下跌5%、现金不变。

三个目标状态的静态压力损失都是37.3%。如果实际仓位因权益上涨而使压力值严格超过44%，恢复当前状态目标。它只是风险预算维护，不会把M60切成D60，也不是组合回撤止损。

### 10.4 C11明确不做什么

- 不把总权益从60%主动降到20%或0%；
- 不根据账户浮亏触发止损；
- D60仍有60%权益，不是真正空仓或纯防守；
- 不在非月末正式动作日自创估值交易；
- 不因一次基金限购就换到未研究的同类基金；
- 不看到历史7.91%就承诺未来达到同样收益；
- 不在结果出现后把30/70阈值改成更好看的数字。

## 11. 标准6:4与C11分别适合谁

### 11.1 标准6:4适合的人

- 投资期限5年以上，紧急资金已经分开；
- 能接受30%左右甚至更高的阶段性回撤；
- 希望一年只处理少数几次再平衡；
- 不想维护PE、PB、指数全收益和交易日历；
- 更重视长期坚持、可解释和少犯错；
- 接受收益主要来自资产本身，而不是频繁择时。

对大多数普通投资者，标准6:4已经足够。长期结果往往更受是否持续执行、是否在低位恐慌卖出、是否保持合理风险预算影响，而不是是否多做一层复杂择时。

### 11.2 标准6:4不适合的人

- 3年内确定要使用本金；
- 无法接受净值下跌20%；
- 把债券基金理解为保本；
- 借钱投资或没有家庭备用金；
- 会因短期排行榜频繁换基金；
- 需要本金保证或稳定固定收益。

### 11.3 C11适合的人

- 已经理解并能够执行标准6:4；
- 愿意每月保存点时数据、公式结果和状态记录；
- 能接受状态机多年停留在同一风格；
- 能处理A类赎回费、确认、到账和限购造成的执行延迟；
- 接受006729增强能力可能衰减；
- 能严格区分研究结果、前瞻验证和真实交易批准。

### 11.4 C11不适合的人

- 希望设置一次自动定投后完全不维护；
- 会在信号冲突时凭感觉“提前切换”；
- 无法验证数据是否在决策时已经可得；
- 因为历史收益更高就愿意承担40%单基金集中；
- 期待C11在熊市自动清仓；
- 需要确定的年化收益目标。

| 指标 | 标准6:4 | C11 |

C11看起来明显优于标准6:4，但必须同时看到：

- 11年历史中真正风格状态切换只有2次；

因此，标准策略可以作为普通投资者的长期实施框架；C11目前更适合作为冻结研究候选进行影子跟踪，而不是因为历史多出2个百分点就立即替换实际账户。

## 17. 常见问题

### 市场跌了15%，要停止定投吗

标准6:4不因跌幅本身停止定投。只要资金期限和风险承受力没有变化，按原计划继续；月末偏离严格超过5个百分点时再平衡。若下跌导致你无法正常生活或睡眠，说明最初权益预算可能过高，应重新做家庭风险规划，而不是临时猜底。

### 某只权益基金赚了30%，要卖一半吗

不采用该规则。先计算市值权重。只有超过目标5个百分点或压力门触发才卖。盈利比例依赖个人买入成本，不适合作为统一组合风险指标。

### 006729表现不好，能换别的中证500增强吗

不能凭近期排名直接换。需要先定义“增强能力衰减”的事前门槛，再对候选产品的费率、规模、经理稳定性、跟踪和历史超额进行独立研究。未完成前保持原基金或暂停新增，不事后挑赢家。

### C11进入D60是不是应该减少总权益

不是。D60只是把权益内部从中盘增强转向红利低波，总权益仍为60%。如果需要真正的股债择时，那是另一套策略，不能在C11内部临时加入。

### 红利再投资是不是免费增加收益

不是。基金分红会降低净值，红利再投资只是把分红现金换成新份额，帮助保持复利和目标暴露。评价收益要使用包含分红的总回报。

### 100万元是否必须全部放在一个平台

不必。分平台可能降低单一渠道风险，但会增加汇总市值、分红设置和费用核对难度。无论几个平台，策略必须按家庭合并后的总市值计算比例，不能每个平台各自做一套60/40。
