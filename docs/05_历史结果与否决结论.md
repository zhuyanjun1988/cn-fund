# 历史结果、压力测试与否决结论

## 1. G6 最终裁决

`G6-Standard-1` 被否决，不进入模拟盘和实盘。主要失败有两个：

1. 历史路径回撤叠加极端冲击的最大损失为 `46.8492%`，超过用户极端压力上限
   `45%`；
2. 32 个滚动三年窗口中，CAGR 达到 10% 的比例只有 `43.75%`，低于预注册的
   `50%` 稳健性门。

这两个失败不能通过改名、缩窄风险口径或只展示全样本 CAGR 来绕过。若研究不同
权重或资产结构，必须作为新的经济候选，而不是在同一候选中事后修补。

## 2. 基础情景

假设：

- 2015-01-05 至 2026-07-30；
- 2740 个共同交易日，按 2739 个收益间隔计 10.869 年；
- 单边全成本 50bp；
- 决策后延迟 2 个共同交易日执行；
- 基金累计净值/总回报语义包含公开分红和拆分修正；
- 每次季度目标按组合净值和价格漂移重新会计。

结果：

| 指标 | 数值 |
|---|---:|
| 期末净值 | `3.100468` |
| 净 CAGR | `10.9720%` |
| 年化波动 | `8.9168%` |
| 最大回撤 | `13.3510%` |
| Sharpe（零无风险利率） | `1.2124` |
| Calmar | `0.8218` |
| 年化 L1 换手 | `44.5836%` |
| 交易事件数 | `47` |
| 相对冻结基准净超额 CAGR | `+0.7243` 个百分点 |

这些指标说明该历史结构值得作为研究参考，但不能消除形成污染和稳健性失败。

## 3. 滚动窗口

### 三年窗口

- 32 个窗口；
- 最低 CAGR `4.8168%`；
- CAGR 达到 10% 的比例 `43.75%`；
- 最坏窗口仍为正，但多数窗口不能稳定达到项目收益目标。

### 五年窗口

- 24 个窗口；
- 最低 CAGR `8.6944%`；
- CAGR 达到 10% 的比例 `75%`。

含义：10.97% 的全样本年化并不意味着任意三年或五年都能达到 10%。投资者实际
进入时点可能对应较弱窗口，必须看分布而不是单个总数。

## 4. 成本、延迟和结算

| 情景 | 净 CAGR | 最大回撤 | 解释 |
|---|---:|---:|---|
| 50bp、延迟 2 日 | `10.9720%` | `13.3510%` | 基础 |
| 100bp、延迟 2 日 | `10.7240%` | `13.3510%` | 高成本 |
| 250bp、延迟 10 日 | `9.7441%` | `13.2942%` | 极端执行压力 |
| 赎回资金等待 10 日零收益 | `10.9324%` | `13.3545%` | 固定交易事件结算敏感性 |

100bp 情景按买卖两侧绝对调仓额收费，不是只扣一次。场外基金管理费、托管费和
销售服务费通常已经反映在净值中，不应重复扣；申购、赎回、佣金、价差、溢价和
结算机会成本则需另外覆盖。

现有费率证据只是起始和当前产品文件形成的保守包络，不是 2015—2026 每一天的
完整 PIT 费率表。更换基金产品后不能继承原代理的成本结论。

## 5. 三种回撤口径

### 常态历史最大回撤

从日净值高水位到后续净值低点：`13.3510%`。

### 静态极端冲击

对当日资产权重施加预注册极端损失因子，最大记录值 `44.0249%`。它回答“若
今天立刻发生这组冲击，按当前权重损失多少”。

### 路径 + 极端冲击叠加

先保留从历史高水位到当日已经发生的回撤，再对当日组合施加极端冲击：

```text
overlay_drawdown = 1 - NAV_today * (1 - static_loss_today) / prior_high_water
```

最大值发生于 2022-10-11，为 `46.8492%`。它更接近用户所说的“最极端压力下
最大回撤”，所以最终风险门失败。

## 6. 会计完整性检查

公开日账本可独立验证：

- 2740 行、日期严格递增；
- 无负权重；
- 权重和最大残差 `7.3e-40`；
- 最大毛权重 `1 + 6.4e-40`，只是 Decimal 舍入，不是杠杆；
- NAV 重算、CAGR 和 MDD 与发布目标一致；
- 路径叠加压力最大日期和数值可由每行 NAV 与压力标量直接重算。

运行：

```bash
make verify-evidence
```

## 7. 为什么不能称为可交易结论

1. 结构形成看过历史结果；
2. 估值历史是回溯捕获，不是完整同期快照；
3. 历史产品限购、份额和费用档案不完整；
4. 美国科技成长重叠对历史收益贡献敏感；
5. 当前 QDII 限购会阻止新组合按目标建立；
6. 尚无合格、不可回填的前瞻业绩样本；
7. 候选已经违反风险和滚动稳健性门。

因此，本项目的价值是保存一个清晰的正负结果：该结构在全样本表现好，却仍不足
以满足用户目标。这比继续调阈值得到一个更漂亮的回测更有研究价值。

## 8. 2026-08-14 国内组合研究增量

G6 否决后，项目先冻结国内标准 6:4 与 C11，随后新开了独立的 C21—C26 经济谱系。
它们不是在 G6 原 ID 中修补，也没有改变 G6 的失败裁决。
