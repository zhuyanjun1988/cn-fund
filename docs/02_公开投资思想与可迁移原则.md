# E 大、银行螺丝钉、孟岩的可迁移思想

## 1. 共同底层逻辑

三套公开理念没有根本冲突。它们关注的层级不同，但可以组合成同一个流程：

```text
资金期限与风险承受能力
  → 多类资产长期配置
  → 每类资产选择合适估值尺
  → 低估分批增加、高估分批减少
  → 用现金/债券承接等待和调仓资金
  → 选择当时可买、低成本、质量合格的基金
  → 通过规则降低情绪和被迫卖出
```

主要张力不是“谁对谁错”，而是择时幅度：孟岩更强调 Beta 底座和长期持有，
螺丝钉强调低估指数的定期不定额，E 大更突出多资产配置、长线/波段分账和动态
平衡。自研策略应把择时定义为风险预算的有限调整，而不是满仓/空仓预测。

## 2. E 大：多资产、逆向分批、动态平衡

最有价值的思想：

1. 总仓位、大类配置和具体买点是三个层次；
2. 权益不押注一个指数，黄金、债券和现金具有主动配置价值；
3. 价格越低于价值，允许投入越多；价格显著高于价值，逐步回收风险；
4. 长线配置仓与波段仓的入场、成本和退出逻辑应分开；
5. 买卖按批次渐进进行，承认估值区域而非精确最低点；
6. 可估值资产以价值为主，黄金等难估值资产更多使用趋势和周期；
7. 产品限购、费用和可用工具会改变最终订单。

E150 全量账本审计了 259 次调整、416 个买卖腿和 61 个基金代码。结果支持它更像
“组合约束优先的多层状态机”，而不是给每只基金算一个分位后独立触发。但公开
资料没有提供完整估值公式、真实市值权重、批次成本和冲突优先级，不能声称复刻。

2018—2019 的关键腿显示至少存在四类不同机制：可估值权益的左侧分批、价值相容
后的右侧确认、黄金等难估值资产的趋势/配置账本，以及独立波段账本。把所有买入
压成“估值分位低于 X”会丢失重要经济含义。

## 3. 银行螺丝钉：指数分类与因材估值

最有价值的思想：

1. 先区分宽基、策略、行业和主题，再谈估值与持有上限；
2. 不同基本面使用不同估值尺：盈利稳定可看 PE/盈利收益率，强周期可结合 PB，
   稳定分红资产重点看股息率；
3. 历史百分位只是辅助，必须检查指数规则、样本长度和估值口径变化；
4. 从低估资产中分散选择少数高质量品种，不是基金越多越好；
5. 没有合格低估机会时，用短债等防守资产中转；
6. 定期不定额和分批止盈把估值差异转成资金动作。

不能迁移的是某个历史时点的单一 PE/PB 数字、星级或名单。指数基本面和市场
中枢会变化，任何阈值都需要自己的点时数据和稳健性检验。

## 4. 孟岩/长钱：资金分层、Beta 底座、行为纪律

最有价值的思想：

1. 只有长期不用、已排除应急需求且无杠杆的资金进入长期权益策略；
2. 长期收益首先来自企业盈利、分红和经济增长，择时是增益而非全部收益来源；
3. 低估多买、极端高估卖出，但不做短周期点位预测；
4. 新钱配置和存量账户调仓是不同问题，新钱优先补缺口；
5. 现金和债券是风险预算，不是回测残差；
6. 规则的首要价值是让普通人长期坚持、避免情绪追涨杀跌。

未公开的市场温度公式、个性化账户数据和连续温度—仓位函数不能推测为事实。

## 5. 本项目如何综合，而不拼接成“伪大师策略”

| 模块 | 主要启发 | 本项目补全 |
|---|---|---|
| 资金准入 | 孟岩/长钱 | 期限、应急金、无杠杆，属于投资者侧前置条件 |
| 资产配置 | E 大 | 明确权重、上下限、相关性和压力预算 |
| 估值适用性 | 螺丝钉 | 为每类指数定义 PE/PB/股息率等独立口径 |
| 分批与动态平衡 | E 大、螺丝钉 | 交易批次、频率、确认期和再入条件 |
| Beta 底座 | 孟岩 | 择时仅做有限倾斜，不用全空全满 |
| 产品落地 | 三者公开实践 | 点时基金身份、规模、跟踪、费率、限购和渠道 |

所有精确参数都标为自研。公开思想只能限定经济结构，不能替本项目证明参数有效。
