# E150 全量逐笔解释工程：阶段一结果

## 结论

E 大长赢 150 已从“可阅读的历史调仓表”升级为可供逐笔解释的、内容哈希绑定的
研究底座：`259` 次调整、`416` 个基金买卖腿、`61` 个基金代码均已连接调整
前后单位状态、资产袖套、现金代理、历史同代码动作和公告定位。

治理复核发现，这批旧产物的 `generated_at` 晚于文件实际创建时间，且生成时
没有绑定实现代码哈希。它们只能作为污染开发数据；内容哈希可校验文件未漂移，
却不能证明合同/代码先于运行。缺口已在新 hash-chain 主账本中如实登记，未
回填旧时间。

当前还**不能**声称已解释全部买卖。冻结的作者文字证据覆盖 `89/259`
次调整和 `118/416` 个同页基金腿；其中只有 2024-12 至 2025 的审计完成了
逐基金腿归因，得到 `11` 个作者直接陈述、`4` 个相关语境和 `7` 个未知事件。
其余同页证据仍必须逐腿复核，不能把一页中的解释平均分给所有买卖。

这一步没有读取任何新策略收益，也没有据历史结果选择阈值。

## 已冻结的数据链

### 全量行为上下文

输入：

- 且慢公开 150 标准目标台账，SHA-256
  `244b040a1412ca7e42356137c0616bc178c074f018ccff8acf3f94a219c036f1`；
- `61` 个基金代码到 `26` 个资产袖套的冻结映射；
- 六份逐调整公告定位索引，覆盖 `259` 次调整，其中 `254` 次有 URL、`5` 次
  保留为空链接事实。

输出：

- `e150_order_leg_context.csv`：`416` 行，每行一个基金方向腿；
- `e150_adjustment_context.csv`：`259` 行，每行一次原子调整；
- 摘要和 manifest。

同一调整内的所有腿统一使用“整次调整之前”的前状态和“整次调整之后”的后
状态，禁止按 Markdown 中的展示顺序虚构先卖后买或先买后卖。卖出所对应的
真实买入批次仍标为未知；当前只保存全部历史买入记录，不默认 FIFO、LIFO 或
作者指定批次。

全量校验结果：

| 校验项 | 结果 |
|---|---:|
| 调整数 | 259 |
| 买入腿／卖出腿 | 261／155 |
| 买入单位／卖出单位 | 267／156 |
| 不同基金代码 | 61 |
| 最新已投资单位 | 111 |
| 最新现金代理单位 | 39 |
| 负库存／总单位超过 150 | 0／0 |

表中单位只可核对公开账本、类别存在、动作方向和相对增减。禁止除以 `150`、
剔除境外后归一化，或将其解释为市值权重、现金/权益比例、压力锚点和自研参数。

### 作者理由证据

首轮纳入八份冻结合同：2017 原文关联、2022 场外片段、2023–2025 理由与版本、
三份 2023 逐页读取增补、2026 年 1–5 月矩阵，以及 2024-12 至 2025 的近期
逐基金腿审计。

| 证据状态 | 条目数 | 含义 |
|---|---:|---|
| `author_statement_present` | 56 | 当页有作者陈述；不等于完整公式 |
| `partial_author_context` | 8 | 有相关语境，但不能唯一导出该动作 |
| `action_only` | 27 | 只有动作或“正常调仓”，没有可归因理由 |
| `unread_or_unavailable` | 6 | 正文尚未取得；不能理解为“没有理由” |
| 合计 | 97 | 覆盖 89 个不同调整 |

近期逐基金腿审计特别验证了状态机不是“低估即买、高估即卖”一个条件：

1. 组合目标和现金边界可以先触发动作；
2. 长期配置腿与波段腿可同时存在；
3. 同一资产还要经过批次成本、时间、价格空间和趋势判断；
4. 限购、额度、规模与费率可以覆盖理论上的最优工具选择；
5. 动态再平衡卖出不等于看空，也不等于清仓。

### 事前市场上下文

既有近年特征资产已按原始哈希重新接入全量 `416` 腿，输出只保留调整日前
可得的净值路径和已核验指数估值字段；四个真值标签列被明确排除。

| 项目 | 覆盖 |
|---|---:|
| 事前净值／价格路径特征 | 416/416（61 个历史基金代码全覆盖） |
| 已核验一一映射的指数估值 | 70/416 |
| 同日或未来净值 | 0 |
| 晚于允许净值日的估值 | 0 |
| 输出中的事件真值标签 | 0 |

这些行只是候选解释变量，不是 E 大的信号。与原近年 126 行逐字段交叉校验为
零差异。尤其不能用前一事件日前净值当作
真实成交成本：例如未知净值申购、QDII 确认、限购和批次选择会令这种代理与
作者回顾收益明显不同。批次收益继续保持未知，不能为了吻合文字改用同日或
未来净值。

## 当前最重要的研究判断

E150 更接近“组合约束优先的多层状态机”，而不是逐基金每天独立计算估值分位：

```text
账户现金与总风险边界
    → 大类／袖套是否缺配或超配
    → 长期配置账本或波段账本
    → 该计划的历史批次、时间与价格空间
    → 当时可申购且全成本可接受的基金工具
    → 分一单位或少量单位执行
```

因此，后续不能再次用“每只基金达到一个局部价格阈值就发信号”的方式拟合
E150。此前该结构在近期样本产生大量非事件日误报，已经构成反证。

## 尚未解决的关键缺口

1. 2015–2022 大量微信页仍只有定位链接，没有逐字理由；
2. 2024 多数调整和 2026 年 6–7 月尚未做逐腿正文审计；
3. 单位库存不是真实市值权重，无法直接判定作者所说的“超配”幅度，且不得
   归一化为现金/权益比例或自研参数；
4. 真实长线／波段批次、成本和卖出批次未公开；
5. 估值、趋势、支撑位、右侧和“时间／空间”的数据源及合成公式未公开；
6. 当时的基金限购、额度、规模和全成本仍需点时产品证据。

## 下一阶段执行顺序

1. 先完成 `416` 腿的证据状态表：直接理由、相关语境、动作事实、未读四类，
   每项绑定来源行和不可推断边界；
2. 对无法取得直接理由的腿，构造竞争性解释，而非单一后验故事：组合再平衡、
   估值／价值、趋势／右侧、时间空间、批次止盈、现金缺口、工具约束；
3. 为每个事件只连接交易日前可得的净值、指数估值、回撤、趋势、相对强弱和
   产品状态；全历史净值路径已完成，下一步补历史估值和点时产品状态；
4. 对每个解释保存支持证据、反证、替代解释、置信度和可证伪条件；
5. 汇总跨年份重复出现且能由事前数据表达的模块，形成 E150 可迁移状态机；
6. 再用螺丝钉的估值适用性和孟岩的资金分层作交叉验证，不能反过来补写
   E150 作者未说过的话；
7. 最后才冻结本项目自研策略，打开历史评价。公开思想负责限定结构，研究者
   参数必须单独署名并事前冻结。

本阶段产物是解释工程和策略设计证据，不是 E 大隐藏算法、客户实盘、收益证明
或可直接跟投的买卖建议。
